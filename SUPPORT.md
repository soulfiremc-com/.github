# Soulfire support

Start with the [documentation](https://soulfiremc.com/docs).
For setup, configuration, accounts, proxies, plugins, and scripts, ask in the [Discord community](https://soulfiremc.com/discord).
Include the project and version, environment, steps, and relevant text logs.
For SDK questions, include the package and runtime versions and a small code example.
Remove tokens, passwords, account data, proxy credentials, and bypass keys before sharing evidence.

## Bugs and proposals

Search the owning repository's open and closed issues before opening a report.
Add new reproduction details to an existing report of the same problem.
Otherwise, use that repository's issue chooser.
If you cannot identify the component, ask in Discord for help.

## Private reports

Use [SECURITY.md](SECURITY.md) for vulnerabilities.
Use [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#report-a-concern) for community concerns.
Do not include private details in a public issue.
