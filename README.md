# SoulFire organization community files

This repository contains the public organization profile and shared contributor resources.
GitHub uses these files for repositories without their own matching community files.
A repository with its own issue templates or issue configuration replaces the entire shared issue template set.

## Files

- [CONTRIBUTING.md](CONTRIBUTING.md): common contribution and review expectations.
- [SUPPORT.md](SUPPORT.md): support channels and the repository directory.
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md): community expectations and private reporting.
- [SECURITY.md](SECURITY.md): confidential vulnerability reporting.
- [.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE): reusable issue forms and support links.
- [.github/pull_request_template.md](.github/pull_request_template.md): default pull request template.
- [profile/README.md](profile/README.md): the public organization profile.

Repository-specific contribution guides describe toolchains, build commands, and tests.
Keep common contacts and policies here so future repositories inherit the same guidance.
The defaults do not appear in other repositories' clones or packaged artifacts.

See [GitHub's default community file documentation](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for file locations and inheritance.
